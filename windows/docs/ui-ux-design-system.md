# UI/UX 설계 기준

이 GUI는 `ui-ux-pro-max`의 운영 도구 기준을 적용한다. 핵심 방향은 화려한 랜딩 화면이 아니라, 사용자가 지금 무엇을 눌러야 하고 어떤 위험이 있는지 즉시 알게 하는 것이다.

## 스타일

- 스타일: Minimalism & Swiss Style 기반의 운영 콘솔
- 구조: 왼쪽 단계 내비게이션, 중앙 실행 패널, 오른쪽 도움말, 하단 로그
- 색상: 청록색은 기본 실행, 주황색은 위험 작업, 어두운 배경은 로그와 내비게이션에만 사용
- 장식: 의미 없는 그래픽보다 상태, 경고, 로그를 우선

## 상호작용

- 기본 버튼은 각 화면에서 하나만 강하게 표시
- 버튼명은 `동사 + 대상`으로 작성
- 위험 작업은 색상만으로 구분하지 않고 확인창과 문구로 다시 설명
- 관리자 권한이 필요한 작업은 일반 exe에서 바로 실패시키지 않고 관리자 exe로 다시 열도록 안내
- 로그는 PowerShell 출력 인코딩을 UTF-8로 강제해서 한글 깨짐을 줄임

## 접근성

- 주요 버튼 높이 48px
- 좌측 내비게이션은 키보드 Enter/Space 선택 지원
- 커스텀 버튼에 포커스 표시와 접근성 이름/설명 제공
- 위험도는 `안전`, `주의`, `위험` 텍스트로도 표시

## 우선순위

1. 실수 방지
2. 현재 상태와 다음 행동 표시
3. 실패 시 로그와 문서로 복구 가능
4. 반복 작업 자동화
5. 시각적 완성도
