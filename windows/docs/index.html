RPI Netboot Manager

Windows PC에서 RPi4 네트워크 부팅을 운영하기 위한 단일 실행 프로그램입니다. 실행 파일은 RPI-Netboot-Manager.exe 하나만 사용합니다.

기준 환경

서버 PC

유선 이더넷은 10.73.0.10/24, 공유기는 10.73.0.1 기준입니다.

저장소

선택한 저장소 아래 tftp에는 부팅 파일, rootfs에는 Pi별 rootfs를 둡니다.

대상 장비

네트워크 부팅 대상은 RPi4입니다. Zero 2 W는 별도 SD + USB gadget 흐름으로 관리합니다.

버튼 순서

1
상태 확인

PC, 저장소, 네트워크, 서비스 포트, 등록된 RPi4 정보를 읽기 전용으로 확인합니다.

2
서버 PC 준비

설정된 저장소 폴더 구조와 유선 이더넷 설정을 RPi4 부팅용으로 맞춥니다.

3
부팅 서비스 시작

DHCP, TFTP, rootfs 서비스를 시작해 RPi4가 네트워크 부팅 요청을 보낼 수 있게 합니다.

4
새 RPi4 등록/복제

기기 번호, serial, MAC을 입력해 새 장비의 bootfs/rootfs 구조와 설정을 만듭니다.

5
RPi4 EEPROM SD

RPi4를 네트워크 부팅 가능 상태로 바꾸는 EEPROM SD를 만듭니다.

6
Zero 2 W Gadget SD

Zero 2 W용 SD 부팅과 USB Ethernet gadget 설정을 준비합니다.

7
도움말

이 문서와 운영 절차 문서를 엽니다.

현재 집중할 일

첫 RPi4 rootfs를 완성하는 것이 핵심입니다.

<저장소>\tftp\d80c0b88 부팅 파일은 준비되어 있고, 다음 단계는 <저장소>\rootfs\d80c0b88를 실제 Linux rootfs로 채운 뒤 RPi4 전원을 다시 넣어 DHCP, TFTP, NFS 부팅 흐름을 확인하는 것입니다.

문제 확인 순서

IP 충돌

Wi-Fi와 유선 이더넷이 같은 대역을 쓰지 않는지 확인합니다.

포트 점유

UDP 67, UDP 69, TCP 2049를 다른 서비스가 잡고 있으면 부팅 서비스 시작 전 정리합니다.

rootfs

etc, usr, bin, sbin 구조가 Pi별 rootfs 폴더 안에 있어야 합니다.
